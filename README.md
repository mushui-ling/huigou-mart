# 惠购百货 · 微信小程序

> 人工智能专业校企合作课程《智能移动应用开发项目实践》实践项目
> 选题：基于 AI 导购的百货超市购物小程序

## 项目简介

面向百货超市线上购物场景的原生微信小程序，实现"浏览挑选 → 加入购物车 → 下单购买"完整购物闭环，并集成 **AI 智能导购助手**（大模型对话/智能推荐）作为课程要求的 AI 能力。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 商品浏览 | 首页搜索、轮播、分类导航、热卖/新品推荐；分类页；商品详情页 |
| 购物车 | 加入/增减/勾选/全选/删除，金额实时合计，tabBar 徽标 |
| 下单购买 | 收货地址表单、订单确认、模拟支付、订单状态流转（待付款→待收货→已完成） |
| AI 导购助手 | 双模式引擎：本地智能推荐引擎（开箱即用）+ 真实大模型 API（可配置） |

## AI 能力设计

- **本地智能引擎（默认）**：`utils/ai-engine.js` 内置意图解析（预算/场景/品类关键词识别）+ 商品检索评分 + 推荐理由生成，无需网络即可演示完整 AI 导购流程。
- **真实大模型 API**：在"我的 → AI 导购引擎配置"中切换到 API 模式，填入 OpenAI 兼容接口（火山方舟 / 通义千问 / DeepSeek 等）的 Key、接口地址与模型名即可。系统提示词约束输出 JSON 结构化推荐（`{"reply": "...", "productIds": [...]}`），调用失败自动回退本地引擎。

## 运行方式

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开工具 → 导入项目 → 选择本目录（`huigou-mart`）；
3. AppID 选择"测试号"即可（`project.config.json` 已默认 `touristappid`）；
4. 编译运行，即可在模拟器/真机预览。

> 说明：商品数据为本地模拟数据（`utils/mock-data.js`），无需后端服务即可完整跑通全部流程。

## 目录结构

```
huigou-mart/
├── app.js / app.json / app.wxss      # 应用入口与全局配置
├── project.config.json               # 开发者工具项目配置
├── utils/
│   ├── mock-data.js                  # 商品/分类/轮播模拟数据
│   ├── storage.js                    # 本地存储封装（购物车/订单/用户/AI配置）
│   └── ai-engine.js                  # AI 导购引擎（双模式 + 提示词工程）
└── pages/
    ├── index/                        # 首页：搜索、轮播、分类导航、热卖/新品
    ├── category/                     # 分类页
    ├── detail/                       # 商品详情页
    ├── cart/                         # 购物车
    ├── order/                        # 结算下单
    ├── orders/                       # 订单列表
    ├── assistant/                    # AI 导购助手
    └── mine/                         # 我的（登录、订单入口、AI配置）
```
